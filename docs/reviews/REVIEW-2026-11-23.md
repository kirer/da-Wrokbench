## 仍然存在的结构性风险

1. **单机 BFF 仍是本机信任边界**：`local.json` 多进程写没有锁；预览票据在 TTL 内可重放；本机路径只做了词法与 realpath 校验，无法防御同机恶意进程在检查后替换文件。
2. **服务端快照模型**：Postgres 全量 JSONB 写入和 `/state` 全量下发不适合大数据量；附件虽加了配额，仍应迁移对象存储。
3. **身份生命周期**：JWT 无吊销、无限流；生产必须依赖短 TTL、网关限流和网络隔离。
4. **UI 自动化不足**：客户端轮询/画布/右栏切换的回归主要靠手动点检，建议把关键路径补进 Playwright。
5. **历史凭据**：`e2e/check-cookie-isolation.mjs` 曾提交真实 DSH token，代码已改但 git 历史仍在；必须轮换对应会话 token，必要时清理历史。
