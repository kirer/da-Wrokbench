# 验收材料

这里存放界面截图和验证产出，不放源码。

## 目录

| 路径 | 说明 |
| --- | --- |
| [`screenshots/app/`](screenshots/app/) | 工作台整体流程截图（登录、引导、工作台、需求、设计、通知、技能等） |
| [`screenshots/legacy/`](screenshots/legacy/) | 早期迭代的界面截图，仅作历史对照 |
| [`../deploy/dsh-sim/screenshots/final/`](../deploy/dsh-sim/screenshots/final/) | 最终验收图：迭代列表/详情、产品原型画布、设计稿画布、容器验证 |
| `../deploy/dsh-sim/screenshots/archive/` | 调试过程图和被替代的旧截图，仅本地保留 |
| [`../deploy/dsh-sim/screenshots/prototypes/`](../deploy/dsh-sim/screenshots/prototypes/) | 仿真设计稿渲染出的 PNG 预览图 |

新的浏览器验证截图默认写到 `deploy/dsh-sim/screenshots/` 根目录；
确认作为最终证据后再移入 `final/`。
