# S11-019 订单列表筛选与空态 · 设计说明

> 本套设计对应需求 S11-019「订单列表筛选与空态优化」。三屏为同一后台页面的三种状态，视觉语言完全一致。

## 一、页面结构

三屏共用统一的页面骨架，自上而下为：

1. **顶栏**：品牌标记 + 「订单中心」标题，右侧为当前用户「王五」头像与名称，高 60px，白底 + 1px 分隔线。
2. **页面标题区**：`订单列表` 主标题 + 「查看并管理店铺内的全部订单」说明。
3. **筛选卡片**：关键词搜索框、订单状态下拉（全部 / 待付款 / 待发货 / 已完成）、下单时间日期范围、重置与查询按钮。已筛选态与空态在此基础上增加「已选条件」chips 行与「清除全部」。
4. **结果卡片**：顶部结果条（条数 + 状态说明），中部为订单表格或空态区，底部分页（默认态 / 已筛选态）。

文件对应：

| 文件 | 状态 | 内容要点 |
| --- | --- | --- |
| `list-default.html` | 默认态 | 筛选区为初始空值；4 行示例订单；分页「共 4 条」 |
| `list-filtered.html` | 已筛选态 | chips「待发货」「近 7 天」；结果条「共 2 条」；表格 2 行命中结果 |
| `list-empty.html` | 空态 | chips「已完成」「近 7 天」；结果条「共 0 条」；空态插画 + 标题 + 说明 + 「清除筛选」按钮 |

订单表格列：订单编号、商品（缩略图 + 名称 + 规格）、状态、金额、下单时间、操作。订单号与「查看详情」使用主色，状态使用三类语义色徽章。

## 二、状态覆盖

- **筛选输入态**：输入框 `focus` 时主色描边 + 3px 半透明主色外发光；`placeholder` 使用浅灰提示色。
- **筛选结果态**：以 chips 显式回显已选条件，每个 chip 可单独移除，也可「清除全部」；结果条同步显示命中条数与筛选提示。
- **空结果态**：表格区不渲染表头与空行，改为居中插画 + 明确文案 + 可操作的「清除筛选」按钮，避免用户陷入死路；插画为内联 SVG（文件袋 + 放大镜 + 减号），无外部图片依赖。
- **按钮态**：主按钮 / 次按钮均定义 `hover`；分页按钮区分激活、普通与禁用；chips 关闭按钮有 `hover` 底色。
- **数据态**：状态徽章覆盖待付款（橙）、待发货（蓝）、已完成（绿）；金额使用 `tabular-nums` 对齐；行 `hover` 有轻微底色反馈。

## 三、颜色、字号与间距

**颜色（按角色定义）**

| 角色 | 色值 | 用途 |
| --- | --- | --- |
| 主色 primary | `#2f6fed` | 主按钮、链接、选中态、焦点环、chips |
| 主色悬停 | `#2559c9` | 主按钮 hover |
| 主色浅底 | `#eaf1ff` | chips 底色、待发货徽章、头像 |
| 页面背景 bg | `#f5f7fa` | 页面底色 |
| 表面 surface | `#ffffff` | 顶栏、卡片 |
| 正文 text | `#1f2329` | 标题、正文 |
| 次要文字 muted | `#646a73` | 标签、说明、时间（对白底约 5.4:1，达 4.5:1） |
| 边框 line | `#e5e8ed` | 卡片、控件边框 |
| 柔和分隔 | `#f0f2f5` | 表格行线 |
| 语义色 | `#b97400` / `#187a41` | 待付款 / 已完成徽章 |

主色仅用于关键操作与少量点缀，整体保持「中性为主、主色点睛」。

**字号阶梯**（正文 14px，一屏不超过 4 档主要字号）

- 12px：字段标签、徽章、表格表头、次要说明
- 13px：结果条、分页、用户名称、chips
- 14px：正文、输入框、按钮、表格单元格、商品名
- 17px / 20px：顶栏品牌 / 页面主标题

中文正文行高 1.5，标题 1.3；中文与数字之间保留空格，标点使用全角。

**间距与形状**（全部为 4 / 8 的倍数）

- 顶栏左右 32px，主内容最大宽 1240px、左右 24px、上 28px、下 64px
- 筛选卡片内边距 20px，字段间距 16px，chips 行上间距 16px + 上边框
- 表格单元格左右 20px、上下 14px；表头 12px / 20px
- 空态上 72px / 下 84px，插画与标题间距 20px，按钮上间距 22px
- 圆角：卡片 8px、控件 6px、徽章 999px、缩略图 6px
- 阴影：克制，主要靠 1px 边框与底色区分层级，不使用大面积投影

## 四、响应式与可访问性

**响应式（以 1440 宽桌面后台为基准）**

- 主内容 `max-width:1240px` 居中，宽屏不拉伸；窄屏自动收缩。
- `≤900px` 断点：筛选字段与日期范围改为整行堆叠、按钮组占满一行且等宽；表格外层 `overflow-x:auto`，表格设 `min-width:880px`，窄屏横向滚动而不挤压变形；分页纵向排列；空态内边距收紧。
- 日期范围两侧日期框 `flex:1` 等分，避免短字断行。

**可访问性**

- 语义结构：`header` / `main` / `section` / `table`（`thead` / `tbody` / `th`），筛选区带 `aria-label`。
- 表单控件均有可见 `<label>` 或 `aria-label`；图标元素 `aria-hidden="true"`，空态插画 `role="img"` + `aria-label`。
- 所有可点区域为真实 `<button>`，高度 ≥ 36px；「查看详情」用 `role="button"` + `tabindex="0"`。
- 统一 `:focus-visible` 主色描边 + 2px 偏移，键盘焦点清晰可见。
- 正文 / 次要文字对白底对比度 ≥ 4.5:1；状态徽章不使用单独颜色传达信息，同时保留文字。
- 交互仅 150ms 的 `background` / `border-color` 过渡，无装饰性动效；不依赖颜色作为唯一信息载体。

## 五、实现约定

- 三屏均为单文件 HTML，CSS 与 JS 内联，不引用任何外部字体、图片、样式或脚本。
- 字体使用系统字体栈：`-apple-system, BlinkMacSystemFont, "PingFang SC", "Microsoft YaHei", system-ui, sans-serif`。
- 设计变量集中定义在每屏 `:root` 中，三屏取值一致，便于统一换肤。
