## 四、建议落地优先级

按「风险 × 投入产出」排序，非按原文编号。

### P0 — 数据/安全，越晚越贵
1. **#45 / #46 / #47 数据层重构**：单行 JSONB 锁全库（PG）+ 全表重写（SQLite）+ 同步锁阻塞 async 线程。三者是同一根问题的三面，必须一起做（拆规范化表 + 领域级细粒度 SQL + `spawn_blocking`/专用写线程），否则并发一上来直接崩。
2. **#33 登录凭证明文存 localStorage**：改安全存储或代理层注入认证头，防 XSS 窃 Token。
3. **#48 吊销黑名单/限流外置**（Redis/DB）+ **#55 反代 ClientIp 解析**：多实例部署下「实例 A 登出、B 仍有效」和「1 人失败封全公司」，都是生产事故级。
4. **#49 PG Webhook 幂等表 + #50 大附件出库**：随数据量增长会拖垮库与备份。

### P1 — 稳定性 / 可维护 / 性能
5. **#25 拆分 client.js 单体**（配 #26 类型、#27 去重 CSS）：一切前端改造的地基。
6. **#28 / #29 轮询改 SSE/增量**：多人协作下的带宽与重渲染瓶颈。
7. **#36 token 漏判 / #37 全局单例串号 / #38 /state 同步阻塞 / #41 local.json 竞态**：BFF 正确性与稳定性。
8. **#13 / #14 / #15 响应式与主题**：窄屏不可用 + macOS 安全区 + 双轨主题，直接影响日常使用。

### P2 — 功能增强 / 流程闭环
9. 产品流程：#1 done/released 终态、#2 cancelled 归档、#3 发布门禁、#4–#8 排期/估时/会签/GitLab 重试。
10. UX：#16–#24（弹窗引导、日期预设、危险操作提示、Markdown 表格、键盘导航、离线条等）。
11. 集成/工程化：#52 通知队列背压与并发、#53 编号并发、#56 前端测试、#58 分支模板、#59 可观测性与 TLS、#60 构建产物治理。
